## What This Project Is About
This project is for my PL/SQL database class. It shows how to write database code to jump around instructions (using GOTO), calculate salaries and taxes using custom functions, and test everything to make sure it works correctly.

## What is Inside This Folder
* **`00_setup/`**: Contains the SQL code to set up our database tables (like employee and department lists).
* **`01_goto/`**: Contains code examples showing how to use GOTO statements to check numbers and review salaries, as well as how to fix common errors.
* **`02_functions/`**: Contains custom database tools (functions) we built to automatically calculate yearly salaries, calculate tax, count years of service, and find department names.
* **`03_tests/`**: Contains test scripts we ran to make sure all our functions work properly when checking employee records.
* **`screenshots/`**: Screenshots of our terminal screen showing that the code ran and gave the correct answers.
* **`docs/`**: A short reflection file explaining what was learned during this project.

## How We Ran It
1. Created the database tables.
2. Loaded all the custom functions into Oracle SQL.
3. Ran the test scripts to check the output.
